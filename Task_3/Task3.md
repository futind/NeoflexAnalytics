## Ответы на вопросы

### В каком виде правильно хранить информацию о соотношении дисциплин, студентов и лекторов?
Информацию о соотношениях дисциплин, студентов и лекторов правильно хранить в смежных таблицах, реализующих отношение "многие-ко-многим", т.к. один студент может быть записан на несколько курсов (например, курс по специальности, курс по выполнению проекта,  общий курс) и на курсе может быть множество студентов; так же и с лекторами - лектор может вести на нескольких курсах, на одном курсе может вести несколько лекторов.

Отношение many-to-many позволяет избергать дублирования данных, упростить обновление данных (возможно удалять данные по студенту/лектору/дисциплине по каскаду) и обеспечить их целостность.
### Приведение к какой нормальной форме должно использоваться при хранении информации о соотношении дисциплин, студентов и лекторов?
При хранении информации о соотношении дисциплин, студентов и лекторов должно использоваться приведение к третьей нормальной форме:
1. 1НФ - в каждом поле каждого кортежа только одно значение (нет массивов), нет дублирующихся строк, все значения в столбце одного типа
2. 2НФ - у каждого отношения есть первичный ключ, и если он составной, то он неприводим
3. 3НФ - нет транзитивных зависимостей, которые 
Данная НФ позволяет избежать дублирования данных и косвенных зависимостей, которые затрудняют обновление.

## Запросы
### Перечень дисциплин, которым прикреплены более 5 студентов
Набор возвращаемых полей: Наименование дисциплины, Количество студентов.
Примечание: Группировку можно производить по наименованию дисциплины.
```sql
SELECT classes.class_name AS "Название дисциплины", COUNT(*) AS "Количество студентов"
FROM students_classes 
JOIN classes ON students_classes.class_id = classes.id
GROUP BY class_name 
HAVING COUNT(*) >= 5
ORDER BY COUNT(*) DESC;
```

## Средний возраст лекторов по дисциплине 
Набор возвращаемых полей: цифра
```sql
SELECT AVG(EXTRACT(YEAR FROM AGE(CURRENT_DATE, lectors.birthdate))) AS "Средний возраст лекторов"
FROM lectors
JOIN lectors_classes ON lectors.id = lectors_classes.lector_id
JOIN classes ON lectors_classes.class_id = classes.id
WHERE classes.class_name = 'Системная аналитика';
```

### Список студентов у которых не указан мобильный телефон
Набор возвращаемых полей: "ФИО" - конкатенация Фамилии Имя и Отчества
```postgresql
SELECT CONCAT(last_name, ' ', first_name, ' ', patronymic) AS "ФИО"
FROM students
WHERE phone_number is null;
```

### Рейтинг популярности дисциплин среди студентов таким образом, что первое место будет занимать дисциплина с наибольшим количеством прикрепленных студентов
Набор возвращаемых полей: Номер места в рейтинге, Наименование дисциплины, Количество студентов на дисциплине.
```sql
SELECT 
	ROW_NUMBER() OVER (ORDER BY COUNT(*) DESC) AS "Номер места в рейтинге", 
	classes.class_name AS "Наименование дисциплины", 
	COUNT(*) AS "Количество студентов на дисциплине"
FROM students_classes
JOIN classes on students_classes.class_id = classes.id
GROUP BY classes.class_name;
```

### Список занятий по «Системный анализ», проведенных в формате «Онлайн» за текущий месяц (занятия, проводимые в текущий день должны попасть в выборку).
```sql
SELECT 
	classes.class_name AS "Название дисциплины",
	DATE(timetable.start_time) AS "Дата проведения занятия",
	timetable.format AS "Название формата"
FROM timetable 
JOIN classes ON timetable.class_id = classes.id
WHERE 
	timetable.format = 'Онлайн' AND
	DATE(timetable.start_time) <= CURRENT_DATE AND
	classes.class_name = 'Системная аналитика'
```
